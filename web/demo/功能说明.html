如何使用

  1. 解压整个压缩包，双击 index.html。无需 Python、Node.js、SSH 服务器或网络连接。
  2. 页面直接进入示例 Grove。顶栏可打开演示指南或重置示例数据。
  3. 服务、节点和文件均使用虚构数据。服务登记、启停、备注等演示修改保存在当前浏览器；终端及文件工作区保存在当前页面，重新加载后恢复。
  4. 不要在演示中填写真实账号、密码或密钥。任意示例 SSH 凭据即可继续向导。

当前版本已实现的功能

以下为 Spearmint 当前运行版本已实现的功能。本包沿用该版本的页面，使用内置数据演示，不连接实际设备。需要真实节点的能力同样使用示例数据，不标为“未完成”。

公网映射FRP 映射入口与服务端点关联、映射状态及管理。使用示例公网入口与映射数据展示，不开通实际公网地址。

操作、告警和审计服务操作回执、审计列表、节点与资源告警。示例离线节点产生告警；启停、登记、备注与更新操作生成记录，可检索。
会话与设置当前会话与撤销、面板显示设置。可撤销示例会话、退出并重新进入演示，修改名称与紧凑显示选项。

推荐演示顺序（约 5 分钟）

  1. 花园总览：介绍成员、服务和资源统计。
  2. 网络拓扑：选择 Thor，展示无公网 IP 节点通过上海转发的路径。
  3. 服务管理：打开 Demo API 日志；停止后重新启动，查看状态与回执变化。
  4. 登记服务：选择 Linux 节点接管 Nginx，或新建多行命令 cd /home/demo/projects、python hello.py --port 8080。
  5. 快速 SSH：选择上海节点，依次输入 help、pwd、ls、cat README.txt；在下方编辑并保存文本，再下载。
  6. 节点播种：选上海为发起节点，填写 nas.example、账号 demo 和任意示例密码，沿向导安装。
  7. 群组更新：检查并发起更新，观察 NAS 从 Grove 获取安装包的进度。
  8. 打开未完成页面，说明移动节点与跨 Grove 连接的规划边界。

打包与数据说明

包内只有 HTML、CSS、JavaScript、图标和文字说明；不包含 Spearmint 后端、可执行程序、真实运行数据、证书、私钥、SSH 凭据或用户会话。所有示例 IP 使用文档保留地址或内网示例地址。JavaScript 用于页面交互与示例状态，直接由浏览器执行。可将整个目录托管为静态网站，也可直接从文件打开。

示例终端不会在电脑上执行命令。支持的命令包括 help、pwd、cd、ls / dir、cat / type、echo、whoami、hostname、date、uname -a、python --version、systemctl status、docker ps、clear / cls、exit。其他命令仅回显提示。
